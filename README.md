# Happy Paws Grooming App

This is a simple web application for Happy Paws Grooming.

## Features

- **Home Page**: Information about services, pricing, and testimonials. Includes a booking form.
- **Contact Support**: A dedicated page for contacting support.

## Getting Started

### Prerequisites

- Python 3
- Flask

### Installation

1. Install dependencies:
   ```bash
   pip install flask
   ```

### Running the Application

1. Start the server:
   ```bash
   python3 app.py
   ```
2. Open your browser and navigate to `http://localhost:5000` to view the home page.
3. Navigate to `http://localhost:5000/contact` to view the contact support page.
